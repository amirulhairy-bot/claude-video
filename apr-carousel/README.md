# APR. Amsyar Pack Rental: carousel IG / TikTok

18 slide penceritaan brand (cover → 14 cerita customer → produk → servis 24 jam → CTA).

- `out/instagram-1080x1350/`: 4:5 untuk Instagram
- `out/tiktok-1080x1440/`: 3:4 untuk TikTok photo mode (TikTok papar gambar dalam bingkai 3:4; teks dijauhkan dari search bar di atas & butang di kanan)
- `CAPTION.md`: caption + hashtag

Ubah teks/kedudukan dalam `render.js` (array `slides`), kemudian jalankan `node render.js`.
Font: Montserrat sahaja (font sama dengan "AMSYAR PACK RENTAL" pada logo), tajuk weight 900. Warna: #4072AF (dari logo).
